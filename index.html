☁ Auto-sync setup

1

Go to jsonbin.io → sign up free → copy your Master Key from the API Keys page.

2

Paste your Master Key below and tap Save key.

3

Tap Create new bin once. Copy the Bin ID that appears and save it — you'll need it on other devices.

4

On another device: paste both the key and the Bin ID, then tap Connect.

💾 Manual backup — save to iCloud

Export a JSON file → tap Share → Save to Files → iCloud Drive. Import anytime to restore.
